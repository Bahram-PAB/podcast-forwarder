# ریمیکس فوارواردر

هر **۸ ساعت** کانال‌های لیست را بررسی می‌کند و هر فایل صوتی یا ویس‌نوت **بیش از ۱۵ دقیقه** را به گروه مقصد کپی می‌کند.

## کارکرد

- آستانه: **۹۰۰ ثانیه** (۱۵ دقیقه) — `audio` و `voice` هر دو بررسی می‌شوند
- مدت از خودِ پیام خوانده می‌شود، پس **قبل از هر دانلودی** فیلتر می‌شود
- انتقال با ارجاع `msg.media` انجام می‌شود: کپی **سمت سرور تلگرام**، بدون دانلود و بدون محدودیت ۵۰ مگابایت
- کپشن: نام کانال در خط اول، مدت‌زمان در خط دوم با ارقام فارسی — بدون جداکننده و بدون خط تاریخ
- هر چیزی که قبلاً فرستاده شده دوباره فرستاده نمی‌شود (`state.json`)

## چرا user session و نه ربات

ربات فقط پیام کانال‌هایی را می‌گیرد که **در آن‌ها ادمین باشد**. کانال‌های این پروژه مال ما نیست، پس راه Bot API کاملاً بسته است. حساب کاربری (Telethon) می‌تواند هر کانال عمومی را بخواند.

پیامد: **حساب کاربری باید عضو گروه مقصد باشد** تا بتواند در آن بنویسد.

## راه‌اندازی

### ۱) حساب کاربری

از [my.telegram.org](https://my.telegram.org) → API development tools، `api_id` و `api_hash` بگیرید.

سپس یک StringSession بسازید. این اسکریپت را **روی کامپیوتر خودتان** اجرا کنید (کد تأیید و پسورد فقط روی دستگاه شماست):

```python
# make_session.py
import asyncio
from telethon import TelegramClient
from telethon.sessions import StringSession

API_ID, API_HASH = 123456, "..."

async def main():
    c = TelegramClient(StringSession(), API_ID, API_HASH)
    await c.start()          # شماره → کد تأیید → (۲فا اگر دارد)
    print(c.session.save())  # خروجی را کپی کنید
    await c.disconnect()

asyncio.run(main())
```

```bash
pip install telethon
python make_session.py
```

> **هشدار:** تلگرام وقتی این سشن از سرور GitHub استفاده شود، اعلان «ورود از دستگاه جدید» می‌فرستد. این طبیعی است و یک‌بار اتفاق می‌افتد.

### ۲) گروه مقصد

حساب کاربری را به گروه اضافه کنید و **دسترسی ارسال پیام** بدهید. شناسهٔ گروه را پیدا کنید:

- با [@userinfobot](https://t.me/userinfobot) عدد را بپرسید، یا
- از لاگ ربات گروه استفاده کنید

### ۳) Secret ها

در GitHub → Settings → Secrets and variables → Actions این چهار مورد را بسازید:

| نام | از کجا |
|---|---|
| `TELEGRAM_SESSION` | خروجی `make_session.py` |
| `TELETHON_API_ID` | my.telegram.org |
| `TELETHON_API_HASH` | my.telegram.org |
| `TARGET_CHAT_ID` | شناسهٔ گروه مقصد (مثلا `-1001234567890`) |

> همین چهار Secret در ریپوی `tg-channel-digest` شما از قبل وجود دارد — همان مقادیر را کپی کنید.

## اولین اجرا چه می‌کند

اولین ران برای هر کانال فقط **خط مبنا** را ثبت می‌کند و چیزی فوروارد نمی‌کند. از ران بعد، فقط پیام‌های تازه بررسی می‌شوند.

فایل‌هایی که **قبل** از فعال‌سازی ارسال شده‌اند، برگردانده نمی‌شوند.

## دربارهٔ بازهٔ زمانی

بازه فقط **تأخیر تحویل** را تعیین می‌کند. `state.json` هر پیام را بعد از ارسال علامت می‌زند، پس ران ساعتی هیچ چیزی را تکرار نمی‌کند و ران روزانه هم چیزی از دست نمی‌دهد — فقط دیرتر می‌رسد.
